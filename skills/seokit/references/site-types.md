# Site-type playbooks

Read the one section that matches the site. A long-term plan item cites an entry here as `playbook: <type>, <entry>` when no finding covers it. A site type with no section here gets no playbook entries.

## SaaS and product sites

- **Build next.** A pricing page whose plans, limits, and prices sit in the raw HTML, not behind client-side JavaScript or "contact sales".
- **Do not.** Publish self-ranked "best X" listicles as an emerging brand: answer engines cite them as category sources and then recommend the established competitors.

## Content and blog sites

- **Do not.** Publish AI-generated posts at scale to cover more queries; Google's scaled content abuse policy names it.

## Documentation and developer sites

- **Build next.** An `llms.txt` index of the docs, since coding assistants fetch docs directly.
- **Do not.** Block `ChatGPT-User` or `Claude-User`: developers ask assistants to read the docs on their behalf.
